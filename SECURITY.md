# Security policy

This package handles confidential reports, so vulnerability reports matter.

## Reporting a vulnerability

Please report it privately. Do not open a public issue or pull request.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose
**Report a vulnerability**
(<https://github.com/dmarsal90/laravel-whistleblower/security/advisories/new>).

Include, if you can, the affected version or commit, a minimal reproduction, and what an attacker
gains (for example reading a report, learning a reporter's identity or guessing a tracking code).

## Supported versions

The project is in development and has no stable release yet. Fixes go to the latest commit on `main`.
